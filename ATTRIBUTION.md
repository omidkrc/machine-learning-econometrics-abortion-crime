# Attribution and Upstream Materials

This repository combines Omid Karami's course replication/report with upstream replication materials for:

**Belloni, Alexandre; Chernozhukov, Victor; Hansen, Christian (2014), “High-Dimensional Methods and Inference on Structural and Treatment Effects,” Journal of Economic Perspectives 28(2): 29-50.**

## Upstream files included here

- `data/levitt_ex.dat` — tab-delimited data for the abortion-crime illustration.
- `code/vendor/lassoShooting.ado` — LASSO implementation distributed with the replication package.
- `source/LevittExample.do` — original Stata replication script for the abortion-crime example.
- `source/README_original.txt` — original replication-package readme.
